# POC Apache CloudStack

Evidências e relatório de execução de uma prova de conceito acadêmica com Apache CloudStack, KVM, NFS e rede Advanced.

## Conteúdo

- `evidencias/`: capturas organizadas por etapa da implantação.
- `relatorio/`: relatório técnico da execução.
- `configuracoes/`: orientação para registros de configuração usados na POC.

Informações de rede presentes nas capturas pertencem exclusivamente ao ambiente de laboratório.
